# 版本路线图与验收标准

> 本文列的是计划与放行条件，不代表任何阶段已经实现。V0.4 和 V0.5 在 V0.3 后允许并行。

| 阶段 | 必做范围 | 明确不做 | 可核验交付与验收 |
| --- | --- | --- | --- |
| V0.0 规划 | 需求、架构、数据契约、评测、开源审计 | 业务实现、部署 | 规划文档齐全；无已完成成果虚构 |
| V0.1 基础 RAG | PDF/Markdown 入库、分块、Embedding、向量检索、生成、基本引用、测试 | BM25、复杂 Agent | 可用示例文档入库并回答；引用关联真实 Document/Chunk/页码；关键测试通过 |
| V0.2 Trusted RAG | BM25+向量融合、Rerank、段落定位、引用支持验证、拒答 | 复杂知识图谱、论文原创算法宣称 | 真实证据可回溯；负样本能标记证据不足；有逐例验证 |
| V0.3 评测/工程基础 | 评测样例、可重复基准、Ragas/自定义指标、CI/pytest、容器化基础 | 全量企业应用 | 复现实验产出样本级数据、模型/参数记录；运行说明可复现 |
| V0.4 CourseRAG | 课程/章节/材料管理、问答 UI、PDF 浏览、毕设对照实验 | 强行加入多 Agent | 面向课程的数据隔离生效；引用可点击定位；论文实验数据可导出 |
| V0.5 EnterpriseAgent | LangGraph 单 Agent、Function Calling、知识检索、只读 SQL、外部 API、工具结果溯源 | 为多 Agent 而多 Agent | 跨文档与业务数据库任务成功；SQL 权限与参数校验测试通过 |
| V0.6 多智能体 | Supervisor/Knowledge/Data/Report 角色、状态持久化、重试、执行追踪 | 无意义角色拆分 | 多步任务可复现；与单 Agent 基线比较成功率/耗时/Token |
| V1.0 最终交付 | 安全、日志、端到端评测、双应用 Demo、部署说明、成果归档 | 生产级大规模 SLA 承诺 | 两个应用均可独立启动/演示；真实测试报告与许可证清单齐全 |

## 执行优先级

1. **P0 共享核心**：V0.1 的可复现问答+来源保留；V0.2 的证据溯源与支持性验证；V0.3 的基准评测。
2. **P0 求职可展示闭环**：V0.5 单 Agent + 真正的 Function Calling + 安全 SQL/API 工具；可在 V0.3 后优先启动。
3. **P1 本科毕设交付**：CourseRAG 的课程章节系统及实验，以学校和导师进度为硬约束。
4. **P1 增强**：V0.6 多 Agent 与持久记忆，只在单 Agent 闭环可靠后进行。
5. **P2 可选**：知识图谱、复杂 GraphRAG、微调、前端美化。

## 阶段停止条件（防止范围膨胀）

- 任一阶段未通过验收，不启动会依赖它的新复杂模块。
- 索引、模型、提示词或证据策略变更，需记录版本并重新运行相关基准。
- 每个阶段记录“新增/修改文件、真实运行命令、测试结果、尚存问题、下一阶段风险”。
- 需保证既能解释关键代码，也能说明其来源；不得用 Fork/部署冒充原创实现。

## V0.1 任务分解

1. 建立 Python 项目、依赖锁定、环境变量模板。
2. 实现 PDF/Markdown 解析，保存 source metadata。
3. 实现切分器并保证 Chunk 可回到 Document/page/span。
4. 接入向量生成与 PostgreSQL + pgvector。
5. 实现 query -> retrieval -> LLM -> structured citations 的最小调用链。
6. 提供最简 CLI 或 API；验证有证据和无证据两种输入。
7. 添加单元/集成测试与运行说明，实测后记录结果。
